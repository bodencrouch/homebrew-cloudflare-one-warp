# Cloudflare One WARP Homebrew tap

Install the unofficial Cloudflare One WARP client:

```sh
brew tap bodencrouch/cloudflare-one-warp
brew install cloudflare-one-warp
```

Cloudflare WARP (`warp-cli`) must be installed separately. The formula is updated by the client release workflow.

Project and releases: https://github.com/bodencrouch/cloudflare-one-warp
Documentation: https://bodencrouch.github.io/cloudflare-one-warp/
